A state read on a kept bridge connection takes 0.4 to 0.8 ms; opening the connection takes about 6 ms, paid once per
script. Starting a new Python process for the command line adds about 250 ms, which the MCP server does not pay.
`focus` takes 1 to 7 ms over the Hyprland socket, `status` 100 ms (its speed sample), `shot` 240 to 580 ms.
